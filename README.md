🎮 Tic Tac Toe Game
A simple Tic Tac Toe game built using HTML, CSS, and JavaScript. Play against a friend and enjoy this classic two-player game!

🚀 Features
✔️ Two-player mode (X vs. O)
✔️ Dynamic UI updates after each move
✔️ Winning detection (rows, columns, diagonals)
✔️ Game reset button to start a new round
✔️ Responsive design for all screen sizes

🛠️ Technologies Used
HTML – For structuring the game layout
CSS – For styling the board and animations
JavaScript – For game logic and interactivity

🎯 How to Play
Player X starts the game.
Players take turns clicking on empty boxes to mark X or O.
The first player to get three in a row (vertically, horizontally, or diagonally) wins!
If all boxes are filled and no one wins, it’s a draw.
Click the "Reset" button to start a new game.
